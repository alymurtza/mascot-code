# Theme colours

`src/shared/themes.ts` is generated by these scripts and contrast-checked against WCAG 2
(body text 7:1, other text and accent text 4.5:1, network colours 3:1). Don't edit it by hand;
change the inputs here and regenerate.

- `themes.py`: the ten regular colours (Cream, Rose, Ember, Champagne, Sunflower, Forest, Mint,
  Ocean, Blue, Violet), each as a light and a dark set. Cream's dark set is the app's espresso
  with the icon's own cream; its light set uses a deeper, toasted cream (#b49268) so buttons and
  progress show on the light page. Writes `themes.json` and fails if any pair misses its contrast.
- `gen_themes_ts.py`: reads `themes.json`, adds the special themes (each light or dark only,
  listed in `SPECIAL` there: page colour and accent), checks every theme, and writes the
  TypeScript file.

```
cd tools/themes
python3 -I themes.py report.txt > themes.json
python3 -I gen_themes_ts.py themes.json ../../src/shared/themes.ts
npx prettier --config ../../.prettierrc.json --write ../../src/shared/themes.ts
```

When a special theme is added or removed, keep these in step:

- `SPECIAL` in `gen_themes_ts.py`
- `SPECIAL` in `src/shared/settings.ts`
- its recipe in `src/renderer/src/backdrop.ts` (ponds: also `PONDS` in `src/renderer/src/pond.ts`)
- its `.bd-<key>` rules in `src/renderer/src/styles.css`
- the expected count in the themes test (`test/e2e/ui.spec.ts`)

The kept special themes are Aurora, Meteor shower, Jellyfish, Sky lanterns, Still night, Night
garden, Glow koi, Cherry blossom, Misty mountains, Desert dunes, Bamboo grove, Koi pond, Garden
pond, Reed corner and Hot air balloons. The six ponds are drawn by `src/renderer/src/pond.ts`
(`PONDS` there lists what each one has).
